# Faz 7 Kullanıcı Kabul Testi Kontrol Listesi

## A. Anket yönetimi
- [ ] Yönetici anket taslağı oluşturabiliyor
- [ ] Taslak yönetim ekranında listeleniyor
- [ ] Yayınlanan anket kullanıcı anket merkezinde görünüyor
- [ ] Kullanıcı cevap gönderince tekrar aynı anketi ikinci kez dolduramıyor
- [ ] Sonuç ekranı kampanya bazlı filtrelenebiliyor
- [ ] Sonuç CSV export düzgün iniyor ve Türkçe karakterler bozulmuyor

## B. Nabız ölçme
- [ ] Kullanıcı günlük nabız kaydı oluşturabiliyor
- [ ] Aynı gün yeni kayıt mantığı beklendiği gibi çalışıyor
- [ ] Anonim işaretli kayıt hata üretmiyor
- [ ] Nabız ekranı boş kayıtla çökmüyor

## C. Bildirim ve tercih yönetimi
- [ ] Bildirim tercihleri kaydedilebiliyor
- [ ] Manuel digest oluşturma çalışıyor
- [ ] Tercihler ekranı mevcut özetleri gösteriyor

## D. Destek ve operasyon
- [ ] Destek kuyruğu açılıyor
- [ ] SLA/escalation ekranı yönetici için açılıyor
- [ ] Operasyon sağlığı ekranı açılıyor
- [ ] Sağlık yenileme işlemi kayıt üretiyor
- [ ] Audit log ekranı açılıyor

## E. Yönetici raporlama
- [ ] Faz 4 dashboard açılıyor
- [ ] Survey analytics açılıyor
- [ ] Support analytics açılıyor
- [ ] Export center açılıyor
- [ ] Günlük metrik yenileme çalışıyor

## F. Yetki ve görünürlük
- [ ] Yetkisiz kullanıcı yönetici ekranlarına doğrudan URL ile giremiyor
- [ ] Menü anahtarı kapalı kullanıcı ilgili ekranı görmüyor
- [ ] Boş veri olduğunda ekranlar 500 vermiyor

## Kabul kriteri
Kritik akışlarda bloklayıcı hata yoksa Faz 7 tamam kabul edilir.
