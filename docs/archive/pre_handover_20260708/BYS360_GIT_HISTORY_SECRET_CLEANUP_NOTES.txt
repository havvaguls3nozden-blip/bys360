BYS360 GIT GEÇMİŞİ VE SECRET TEMİZLİĞİ NOTU

Bu not otomatik çalıştırılacak bir script değildir. Çünkü Git geçmişi temizliği geri dönüşü zor bir işlemdir.
Önce yedek alınmalı, ekip bilgilendirilmeli, canlı/parola rotasyonu yapılmalıdır.

Eğer .env veya gerçek parolalar daha önce commit edildiyse:

1. İlgili parolaları/tokenları değiştirin.
   - PostgreSQL parolası
   - SECRET_KEY
   - TCKN_ENCRYPTION_KEY
   - Sentry DSN
   - Redis/Celery bağlantı bilgileri
   - Mail bilgileri
   - Instagram/API tokenları

2. .gitignore düzeltmesini uygulayın.

3. Git index'ten kaldırın:
   git rm --cached .env
   git rm -r --cached .venv .backup .quality_backup
   git add .gitignore .env.example scripts reports
   git commit -m "chore: clean repo hygiene and remove local artifacts from tracking"

4. Git geçmişinde secret kaldıysa git-filter-repo veya BFG Repo-Cleaner ile tarihçe temizlenmelidir.

Örnek git-filter-repo mantığı:
   git filter-repo --path .env --invert-paths

Dikkat:
- Bu işlem remote geçmişini değiştirir.
- Ortak çalışan herkesin yeniden clone alması gerekebilir.
- Kurum reposunda uygulanmadan önce mutlaka ayrı yedek alınmalıdır.
