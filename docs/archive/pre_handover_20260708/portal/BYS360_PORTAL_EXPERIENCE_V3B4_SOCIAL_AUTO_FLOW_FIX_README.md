# BYS360 Portal V3B4 — Sosyal Medya Aktarım Akışı Düzeltmesi

Bu paket iki sorunu düzeltir:

1. Sol şeritte aynı sosyal medya sekmesinin iki defa görünmesini temizler.
2. `/portal/social-import` ekranını üç aşamalı kullanıma çevirir:
   - Önce Tara
   - Bulunanları Gör
   - Bulunanları Paylaş

Zamanlanmış görev çalışırsa otomatik kontrol + otomatik yayın davranışı korunur.
