# BYS360 Portal V3B3 — Sosyal Medya Gönderisi Ekle Ekranı

Bu overlay `/portal/social-import` ekranını canlı ürüne uygun hale getirir.

## Amaç
- Mavi linkli/taslak görünümü kaldırmak.
- Kurumsal kırmızı tema, kartlı yapı ve gerçek butonlar kullanmak.
- X/Instagram bağlantılarını normal portal gönderisi olarak yayın akışına eklemek.
- Ayrı sosyal medya kartı oluşturmamak.
- Hesap kontrolü, tek bağlantı, toplu bağlantı, bekleyenler ve son raporu tek ekranda toplamak.

## Not
API kullanılmadan kurumsal hesap kontrolü platformların herkese açık sayfa yapısına bağlıdır. Platform erişimi engellerse link ekleme ve toplu bağlantı havuzu güvenli kanal olarak çalışmaya devam eder.
