# BYS360 Mobile Security Suite Gate P4C

P4C, P4A ve P4B V3 mobil güvenlik kapılarını tek raporda birleştirir.

- P4A: Yetkisiz ve malformed token koruma matrisi
- P4B V3: Sahte rol/header/token taklidi sınır matrisi
- Mobil route sözleşmesi: `routes.py` facade, domain dosyaları, 24 route decorator
- Güvenlik: secret gate finding count 0 beklentisi

Canlı veriye yazmaz. Mevcut raporları ve test ortamı duman kontrollerini kullanır.
