# BYS360 Kurumsal Bilgilendirme Merkezi V3.0 Faz 7 Geri Dönüş Planı

Versiyon: `BYS360_CORPORATE_INFORMATION_CENTER_V3_0_PHASE7_LIVE_RELEASE_USAGE`

## Amaç
Canlı geçiş sırasında beklenmeyen sorun oluşursa sistemin hızlıca önceki güvenli duruma alınmasını sağlar.

## Geri dönüş adımları
1. Uygulamayı durdurun.
2. Faz 7 uygulamasından önce oluşan `.phase7_live_release.bak` yedeklerini kontrol edin.
3. Sorun yalnızca arayüz ise CSS / template yedeklerini geri alın.
4. Sorun gönderim akışı ise gerçek gönderimi kapatın ve kuru çalışma moduna dönün.
5. Logları saklayın; silmeyin.
6. Uygulamayı yeniden başlatın.
7. Sadece pilot kullanıcı ile tekrar test edin.
