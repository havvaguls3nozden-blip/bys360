# BYS360 DA-21H5B Visible Turkish Local UI

## Amaç

Dijital Arşiv ekranlarında kullanıcıya görünen metinlerin Türkçe, sade ve kurumsal dile uygun olduğu doğrulanmıştır.

## Yapılanlar

- Liste ekranı başlıkları sayfa türüne göre Türkçeleştirildi.
- Form ekranı başlıkları sayfa türüne göre Türkçeleştirildi.
- Kolon ve alan etiketleri Türkçeleştirildi.
- Kontrol betiği görünür metin üzerinden çalışacak hale getirildi.
- Ana sayfa, liste ekranları ve güvenlik ekranının birbirinden ayrıldığı doğrulandı.

## Sonraki Aşama

Local ortamda gerçek kayıt ekleme, listeleme ve düzenleme akışları tamamlanacaktır.
