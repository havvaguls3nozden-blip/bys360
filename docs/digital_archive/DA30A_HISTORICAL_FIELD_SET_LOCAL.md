# BYS360 DA-30A Tarihi Alan Hazır Özel Alan Seti

## Amaç

Çanakkale Savaşları Gelibolu Tarihi Alan Başkanlığı arşiv ihtiyaçlarına uygun hazır özel alan seti eklenmiştir.

## Eklenen Alanlar

- Muharebe Alanı
- Cephe / Sektör
- Tarihsel Dönem
- İlgili Şehitlik / Anıt
- İlgili Köy / Mevki
- Birlik / Alay
- Komutan / Şahıs
- Belge Dili
- Kaynak / Koleksiyon
- Envanter No
- Koruma Durumu
- Açıklama / Tarihsel Not

## Yapılanlar

- Hazır özel alan seti ekranı eklendi.
- Hazır alanlar tek işlemle özel alan tanımlarına eklenebilir hale getirildi.
- Aynı alanın tekrar tekrar eklenmemesi sağlandı.
- Local ortamda hazır alanların eklendiği doğrulandı.

## Sonraki Aşama

Arşiv malzemesi türleri ve fiziksel arşiv sınıflandırması geliştirilecektir.
