Bu overlay, Kurumsal Bilgilendirme Merkezi sayfalarını `/performans/v2/faz3` tasarım yaklaşımına yaklaştırır.

- V4.1B tarafından eklenen yanlış üst başlık ve sekme şeridini kaldırır.
- Eski V4.1/V4.2/V4.3 tasarım katmanlarını etkisizleştirir.
- Genel Bakış ve Kutlamalar aktiflik çakışmasını düzeltir.
- Hero, metrik, sekme, kart ve tablo yüzeylerini sade kurumsal stile taşır.
- “Pilot önce / kuru çalışma” gibi ifadeleri “Aktif / Pasif / ön kontrol / önizleme” diline çevirir.
