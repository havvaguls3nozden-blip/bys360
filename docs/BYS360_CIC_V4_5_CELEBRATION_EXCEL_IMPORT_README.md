# BYS360_CIC_V4_5_CELEBRATION_EXCEL_IMPORT

Kurumsal Bilgilendirme > Kutlamalar ekranına Excel ile doğum günü ve işe başlama tarihi yükleme paneli ekler.

## Kolonlar
- Sicil No
- Ad Soyad
- E-posta
- Doğum Tarihi
- İşe Başlama Tarihi
- Kutlama Dışı
- Not

Ön kontrol veritabanına yazmaz. Uygula seçeneği eşleşen personelin `birth_date`, `hire_date`, `celebration_opt_out` alanlarını günceller.
