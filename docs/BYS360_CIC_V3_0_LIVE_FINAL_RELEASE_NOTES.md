
# BYS360 Kurumsal Bilgilendirme Merkezi V3.0 — Canlı Final Release Overlay

Bu paket, yerelde Faz 2.3–Faz 7.12 arasında doğrulanan Kurumsal Bilgilendirme Merkezi geliştirmelerini canlıya tek komutla taşımak için hazırlanmıştır.

Önerilen uygulama:
1. Canlıda veritabanı ve proje klasörü yedeği alın.
2. Uygulama servisini durdurun.
3. Bu overlay'i proje köküne açın.
4. `scripts/windows/apply_bys360_cic_v3_0_live_final_release.ps1` scriptini çalıştırın.
5. Kontrol scriptini çalıştırın.
6. Uygulamayı başlatın ve önce kuru çalışma / pilot test yapın.

Güvenlik notu: İlk canlı testte gerçek toplu gönderim açılmamalı; pilot alıcı ile log oluşumu doğrulanmalıdır.
