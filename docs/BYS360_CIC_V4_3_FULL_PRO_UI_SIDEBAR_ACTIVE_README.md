# BYS360 Kurumsal Bilgilendirme Merkezi V4.3

Bu overlay:

- Sol şeritte Genel Bakış/Kutlamalar aktiflik çakışmasını düzeltir.
- Kurumsal Bilgilendirme iç sekmelerini net aktiflik mantığına alır.
- Hero alanını BYS360 kurumsal çizgisine uygun sade, cam efektli ve okunur yapıya taşır.
- "Pilot", "Pilot önce", "Kuru çalışma" gibi canlı kullanıcıya uygun olmayan ifadeleri kurumsal dile çevirir.
- Eski CSS katmanları kalsa bile V4.3 CSS en son yüklenerek ekranı toparlar.

Görünen kullanıcı metinlerinde "premium" ifadesi kullanılmaz.
