# BYS360 Portal V3B5 — Uygulama İçinden Otomatik Kontrol Ayarları

Bu paket `/portal/social-import` ekranına otomatik kontrol yönetimi ekler.

- Otomatik Kontrolü Aç
- Şimdi Çalıştır
- Otomatik Kontrolü Kapat
- Sonraki/son çalışma durumu

Kullanıcı PowerShell komutu çalıştırmak zorunda kalmaz. Kalıcı zamanlama arka planda Windows Görev Zamanlayıcı ile yönetilir.
