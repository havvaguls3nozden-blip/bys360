# BYS360 Portal Experience V2A - Canlı Metin Temizliği

Bu overlay, Portal V2 ekranındaki geliştirme/versiyon dilini canlı kullanıcıya uygun sade kurumsal dile çeker.

## Değişiklikler

- `Kurumsal Portal V2` -> `BYS360 Kurumsal Portal`
- `Kurumsal akış, takdir kültürü ve profil görünürlüğü tek ekranda` -> `Kurum içi bilgilendirme, paylaşım ve takip alanı`
- `Portal V2 ... güvenli deneyim katmanı` açıklaması kaldırıldı.
- Duyuru, teşekkür ve profil alan başlıkları daha canlıya uygun hale getirildi.
