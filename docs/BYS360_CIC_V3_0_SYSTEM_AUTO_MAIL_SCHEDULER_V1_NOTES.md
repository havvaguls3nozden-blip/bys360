# BYS360 CIC V3.0 Sistem Kontrollü Otomatik Mail Zamanlayıcı V1

Bu paket Kurumsal Bilgilendirme Merkezi için tek bir Windows yoklama görevi kurar.
Mail görevlerinin aktif/pasif durumu ve saatleri BYS360 > Kurumsal Bilgilendirme > Görevler ekranından yönetilir.

Windows görevi sadece 5 dakikada bir BYS360 sistem ayarlarını okur ve zamanı gelen aktif görevleri çalıştırır.
