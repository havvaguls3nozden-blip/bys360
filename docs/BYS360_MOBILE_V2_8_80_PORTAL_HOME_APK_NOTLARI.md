# BYS360 Mobile Portal Entegrasyonu - Kapsam Notu

Bu paket, portalı Android APK içinde ilk görünür ve kullanılabilir seviyeye getirir:

1. APK ana sayfasında portal giriş kartı.
2. Sol menüde portal satırı.
3. Native Flutter portal merkezi.
4. Portal içinden duyurular, personel portalı, profil, destek ve asistan yönlendirmeleri.

Bu paket WebView eklemez. BYS360 mobil hedefindeki native Flutter yaklaşımı korunur.

Sonraki adımda backend portal API endpointleri kesinleşirse, bu portal merkezi gerçek liste/veri ekranlarına genişletilebilir.
